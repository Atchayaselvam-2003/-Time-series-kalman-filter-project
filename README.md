 # Advanced Time Series Forecasting with SSM & Kalman Filter

## Project Overview
This project focuses on advanced multivariate time series forecasting using State Space Models (SSM) and the Kalman Filter. Unlike traditional forecasting models, it estimates hidden states (trend, seasonality) from noisy data.

## Synthetic Dataset
- Multivariate (3 variables)
- Trend + multiple seasonalities (daily, weekly, monthly)
- Noise and structural breaks
- Correlated noise across variables

## Features
- State Space Model implemented from scratch using Python
- Kalman Filter for state estimation
- Sensitivity analysis for Q and R
- Forecast comparison with Exponential Smoothing baseline
- Plots of states, forecasts, and residuals
